# Wither Plus

Reworks the vanilla Wither into a three-stage boss with soul flames, bone attacks and a black sun. Includes configurable combat, synchronized visual effects, custom shaders and screen effects.

重做原版凋零，提供魂焰、骸骨、黑日主题的三阶段 Boss 战，以及可配置战斗、技能特效、自定义着色器和屏幕效果。
